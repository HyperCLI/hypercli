The Python CLI (`hyper`) is EOL as of 2026-09-09 and is retained for reference only.
The replacement is the TypeScript CLI in `../ts-cli` (`@hypercli.com/cli`, bin `hyper`),
built on `@hypercli.com/sdk` (`../ts-sdk`). Do not add features here. This tree is
excluded from active CI and release-version projections.
