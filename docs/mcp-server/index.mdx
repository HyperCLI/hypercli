The hosted HyperCLI MCP endpoint exposes platform tools through
[Model Context Protocol](https://modelcontextprotocol.io). Discover the tool
catalog from the connected server; availability depends on the deployment
and your credentials.

## Endpoint

```
https://api.hypercli.com/api/mcp
```

## Authentication

Provide your API key as a Bearer token in the Authorization header. Get your API key from the [Dashboard](https://console.hypercli.com).

## Claude Code

For clients accepting HTTP MCP configuration:

```json
{
  "mcpServers": {
    "hypercli": {
      "type": "http",
      "url": "https://api.hypercli.com/api/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}
```

Or via CLI:

```bash
claude mcp add hypercli --transport http https://api.hypercli.com/api/mcp \
  --header "Authorization: Bearer YOUR_API_KEY"
```

## Other clients

Use your client's remote HTTP MCP setup and configure the endpoint and bearer
header above. Client-specific configuration files and remote-server support
vary; a stdio-only client cannot consume an HTTP URL as an executable command.

## Available Tools

The following are examples from the platform catalog. Use MCP `tools/list`
for the connected server's authoritative names, descriptions, and input schemas:

| Tool | Description |
|------|-------------|
| `balance` | Check your account balance |
| `me` | Read account context |
| `render_catalog` | Discover published families, templates and writable inputs |
| `render_submit` | Submit `{family, template, inputs}` |
| `flow_get_render` | Get an owned render result |
| `flow_get_render_status` | Check an owned render's state and progress |
| `flow_cancel_render` | Cancel an owned render |
| `hyper_user` | Read canonical account profile Markdown (read-only) |
| `hyper_soul` | Read canonical Agent soul, with optional explicit `agent_id` (read-only) |
| `hyper_role` | Read canonical Agent role identifier, with optional explicit `agent_id` (read-only) |

## Example Usage

Once configured, you can ask Claude:

- "Check my HyperCLI balance"
- "Discover the Qwen image and LTX video templates and their exact input names"
- "Generate an image with qwen21/image_qwen_image_2_1_t2i and prompt: a quiet forest"
- "Check the status and output URL of render abc"
- "Cancel render abc"

Bind media using `{"file_id": "OWNED_FILE_ID"}` under the exact catalog input
name. Upload separately through an authorized files client; MCP has no local-file
upload/download tools and cannot read paths on your machine. A `flows:*` key can
bind already-owned ready media; uploading requires separate files permissions.
Active render entitlement includes all published templates. Restricted credentials
remain restricted, and submission failures never authorize a paid retry.

## Transport

The server uses streamable HTTP transport (recommended for web clients). Health checks are available at `/api/mcp/health`.
