## Published catalog

| Family | Template | Task |
| --- | --- | --- |
| `qwen21` | `image_qwen_image_2_1_t2i` | Text to image |
| `qwen21` | `image_qwen_image_2_1_image_edit` | Image editing |
| `ltx23` | `video_ltx2_3_t2v` | Text to video |
| `ltx23` | `video_ltx2_3_i2v` | Image to video |
| `ltx23` | `video_ltx2_3_ia2v` | Image and audio to video |

Discover exact writable input names, types, defaults and required media from
`client.renders.catalog()` or `hyper flow catalog`. Model selection and GPU
placement are server-managed. These are the only managed ComfyUI templates;
independent speech synthesis and transcription services remain available.

```python
catalog = client.renders.catalog()
render = client.renders.submit(
    "ltx23", "video_ltx2_3_t2v",
    {"value": "clouds moving over mountains"},
)
```

Bind media by its published input name to `{"file_id": owned_file_id}`.
Do not submit worker paths, arbitrary nodes, model selectors, or image URLs.
For Qwen edit, the fifth image input is the literal key `images.image_5_1`.
For LTX IA2V, `value` is the prompt, `input` the image, and `audio` the audio.

Generic workflow converters and user-managed ComfyUI jobs are separate SDK
facilities; upstream template availability does not imply managed Render support.
See [Renders](/sdk/renders) for submission, tracking and cancellation.
