---
title: Job monitoring
description: Stream job logs with the supported CLI.
---

The Python CLI's full-screen job monitor has been removed.
Use [hyper jobs](/cli/commands/jobs) for job state and streaming logs:

```bash
hyper jobs get <job_id>
hyper jobs logs <job_id> --follow
```

The supported CLI does not implement `--tui` or `--cancel-on-exit`.
For metrics, use the [Python jobs SDK](/sdk/jobs).
