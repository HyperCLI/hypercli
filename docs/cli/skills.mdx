HyperCLI publishes task-focused agent skills alongside the CLI source. Each
skill is a concise operating guide for one command family; the command pages
linked below remain the detailed CLI reference.

## Managed-image discovery

Managed coding-agent images install a pinned HyperCLI checkout at
`/opt/hypercli`. The canonical skill bodies are available at
`/opt/hypercli/skills/<name>/SKILL.md`.

The image exposes those skills to supported harnesses through symlinks:

- `$HOME/.buzz/.agents/skills/<name>` for agent skill discovery
- `$HOME/.buzz/.claude/skills/<name>` as Claude compatibility aliases

`$HOME/SKILLS.md` is a human-readable index, symlinked from
`/opt/hypercli-buzz/SKILLS.md`. It helps agents and operators find the
installed guides, but runtimes do not automatically load it as instructions.
Open the relevant `SKILL.md` before using that command family.

The core `hypercli` skill deliberately limits direct inference to
`hyper llm image`, `hyper agent embed text`, and `hyper agent embed test`.
Use the current harness for ordinary reasoning and `hypercli-flows` for managed
image and video generation. Lower-level inference and workflow surfaces are
outside the shipped skill set.

The repository paths above are canonical. Image symlinks are discovery aids;
do not maintain separate copies of a skill body in a runtime-specific
directory.
