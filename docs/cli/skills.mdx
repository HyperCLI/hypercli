HyperCLI publishes task-focused agent skills alongside the CLI source. Each
skill is a concise operating guide for one command family; the command pages
linked below remain the detailed CLI reference.

## Managed-image discovery

Managed coding-agent images install the canonical skill bodies at
`/opt/hypercli/skills/<name>/SKILL.md`.

OpenCode reads this directory through its generated config. Images do not
create workspace skill symlinks or a static Markdown skill index.
Open the relevant `SKILL.md` before using that command family.

`hyper skills list` and `hyper skills export <dir>` use the generated JSON
catalog installed alongside these skill directories and work offline.

Use the current harness for ordinary reasoning and `hypercli-flows` for managed
image and video generation. The supported command surface is the
[TypeScript CLI](/cli/index); account billing, keys, workspaces, and direct
inference also have SDK/API interfaces linked from their reference pages.
Local memory import and the retired embedding commands are not CLI features.

The repository paths above are canonical. Do not maintain separate copies of
a skill body in a runtime-specific directory.
