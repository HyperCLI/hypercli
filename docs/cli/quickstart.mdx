## Install

```bash
npm install -g @hypercli.com/cli
```

Requires Node.js 22+. See [CLI](/cli/index) for supported command groups.
For Python API integrations, use the [Python SDK](/sdk/index).

## Configure Platform Access

```bash
hyper configure
```

Verify:

```bash
hyper me
hyper jobs list
```

## Launch A GPU Job

```bash
hyper jobs create --image nvidia/cuda:12.6.3-runtime-ubuntu22.04 \
  --gpu l40s \
  -- nvidia-smi
```

Then inspect it:

```bash
hyper jobs list
hyper jobs logs <job_id> -f
```

Use `hyper jobs gpus` for inventory. Account purchases are available through the
[plans dashboard](https://agents.hypercli.com/plans); programmatic account
inspection uses the [SDK](/sdk/agents).

## Create An Agent

```bash
hyper agents create docs-demo --runtime openclaw
hyper agents wait docs-demo --state STOPPED
hyper agents start docs-demo
hyper agents wait docs-demo --state RUNNING
hyper agents status docs-demo
```

No public route ships on the base image (the pod gateway is loopback-only), and
desktop is disabled by default. For a browser desktop, see
[Remote Desktop](/agents/remote-desktop).

## Connect To The Agent

Shell and logs are backend WebSocket flows:

```bash
hyper agents shell docs-demo
hyper agents logs docs-demo -f
```
