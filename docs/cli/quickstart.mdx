---

## Install

```bash
npm install -g @hypercli.com/cli
```

Requires Node.js 22+. The legacy Python CLI (`pip install hypercli-cli`) is
end-of-life and retained for reference; see [CLI](/cli/index#implementations)
for which groups ship in each implementation.

## Configure Platform Access

```bash
hyper configure
```

Verify:

```bash
hyper me
hyper jobs list
```

## Launch A GPU Job

```bash
hyper jobs create --image nvidia/cuda:12.6.3-runtime-ubuntu22.04 \
  --gpu l40s \
  -- nvidia-smi
```

Then inspect it:

```bash
hyper jobs list
hyper jobs logs <job_id> -f
```

The Python implementation adds GPU inventory browsing and interactive shells:
`hyper instances list`, `hyper jobs shell <job_id>`.

## Agent Plans, Subscriptions, And Wallet Checkout

These account commands currently ship in the Python implementation:

```bash
hyper agent plans
hyper agent subscribe solo
hyper agent status
```

## Create An Agent

```bash
hyper agents create docs-demo --runtime openclaw
hyper agents start docs-demo
hyper agents status docs-demo
```

No public route ships on the base image (the pod gateway is loopback-only), and
desktop is disabled by default. For a browser desktop, see
[Remote Desktop](/agents/remote-desktop).

## Connect To The Agent

Shell and logs are backend WebSocket flows:

```bash
hyper agents shell docs-demo
hyper agents logs docs-demo -f
```
