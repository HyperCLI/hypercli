---
title: Workspace APIs
description: Manage shared knowledge through supported SDKs.
---

The former `hyper workspaces` command was removed with the Python CLI.
Use the [Python Workspace SDK](/sdk/workspaces) or
[TypeScript Workspace SDK](/ts-sdk/workspaces) for workspace files, search,
grants, manifests, downloads, and synchronization. The supported TypeScript
CLI does not register a `workspaces` group.
