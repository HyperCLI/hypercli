---
title: Billing APIs
description: Inspect balances and billing through supported SDKs.
---

The former `hyper billing` command was removed with the Python CLI.
Use the [Python billing SDK](/sdk/billing) for balances and transactions,
or the [plans dashboard](https://agents.hypercli.com/plans) for purchases.
The supported CLI's `hyper me` reports identity and entitlement information;
see [configuration](/cli/configuration).
