title: Direct inference
description: Use the supported inference APIs for chat and image analysis.
---

The former `hyper llm` command was removed with the Python CLI.
Use an OpenAI-compatible or Anthropic-compatible client against the hosted
inference API. See the [inference quickstart](/inference/quickstart) for Python
and HTTP examples. `@hypercli.com/cli` does not register an `llm` group.
