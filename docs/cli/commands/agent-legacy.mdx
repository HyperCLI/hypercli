---
title: Retired account commands
description: Migrate retired account commands to supported SDK and CLI surfaces.
---

The Python CLI has been removed. Install the supported CLI with
`npm install -g @hypercli.com/cli` (Node.js 22+).

- Use [hyper me](/cli/configuration) for identity and entitlements.
- Use [hyper agents](/cli/commands/agents) for managed agents and grant redemption.
- Use [hyper agent](/cli/commands/agent) for canonical soul and role metadata.
- Use the [Python SDK](/sdk/agents) for plan discovery and account APIs.
- Purchase capacity in the [plans dashboard](https://agents.hypercli.com/plans).

The former onboarding, wallet subscription, local transcription, and embedding
commands are not supported CLI commands. For inference use the
[API quickstart](/inference/quickstart).
