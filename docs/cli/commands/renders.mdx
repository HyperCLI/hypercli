---
title: Render interfaces
description: Use managed flows or the lower-level render SDKs.
---

For the supported CLI, use [hyper flow](/cli/commands/flow).
The former `hyper renders` command was removed with the Python CLI.

For lower-level render jobs, use the [Python renders SDK](/sdk/renders),
[TypeScript renders SDK](/ts-sdk/renders), or [Render API](/render/index).
