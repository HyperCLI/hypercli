---
title: hyper voice
description: Text-to-speech, voice cloning, and speech-to-text commands.
---

`hyper voice` contains the TypeScript CLI voice commands.

Remote generation commands use the subscription voice API under
`/agents/voice/*` and require a key with `voice:*`.

Global output format is controlled by `--json` or `--output json`. File
destinations use `--out`.

## tts

```bash
hyper voice tts "Hello world"
hyper voice tts "Hello world" --voice ivy --out hello.mp3
hyper voice tts "Long text..." --stream --out long.mp3
```

Defaults:

- `--voice serena`
- without `--out`, writes `tts-<timestamp>.mp3` in the current directory

Without `--stream`, the command posts to `/agents/voice/tts`. With `--stream`,
it opens the agents WebSocket `/ws/voice` endpoint and saves the collected audio
chunks.

Useful options:

- `--voice`
- `--stream`
- `--out`
- `--json`

## clone

```bash
hyper voice clone "Hello" --file voice.wav --out cloned.mp3
hyper voice clone "Hello" --url https://example.com/voice.wav --out cloned.mp3
```

Provide exactly one reference source:

- `--file` reads local reference audio.
- `--url` downloads reference audio client-side, then sends the bytes through
  the SDK.

The TypeScript CLI accepts only HTTPS reference URLs and rejects localhost plus
private, link-local, multicast, and reserved IP literal targets. Reference audio
is capped at 25MiB. Without `--out`, clone writes generated audio bytes to
stdout; use `--out` with `--json`.

Useful options:

- `--file`
- `--url`
- `--out`
- `--json`

## transcribe

```bash
hyper voice transcribe speech.wav
hyper voice transcribe speech.wav --language en
hyper voice transcribe speech.wav --rest --out transcript.txt --json
```

By default, transcription uses the agents WebSocket `/ws/voice/transcribe`.
`--rest` posts to `/agents/voice/transcribe` instead.

Useful options:

- `--language`
- `--rest`
- `--out`
- `--json`

## Python CLI Notes

The Python Typer CLI has additional voice options and aliases. For clone,
`--ref` and `-r` are aliases for the local reference file, and Python also
accepts `--file`. Python TTS and clone still support Python-specific flags such
as `--format`, `--timeout`, `--key`, and `--base-url`; those flags are not
supported by the TypeScript CLI documented above.
