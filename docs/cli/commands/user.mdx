---
title: hyper user
description: Show the current authenticated user.
---

This command belongs to the legacy Python CLI (`hypercli-cli`), which is
end-of-life. The TypeScript CLI provides `hyper me` for identity inspection.

## user

```bash
hyper user
hyper user --output json
```

`hyper user` is implemented as the command group's callback, so running the group itself prints the current user record.
