## Discover the deployment catalog

```bash
hyper flow catalog --json
hyper flow catalog --family ltx23 --json
hyper flow describe ltx23 video_ltx2_3_ia2v --json
```

Discovery reads `/agents/flow/catalog` directly without entitlement routing.
Descriptors expose exact input names,
types, defaults, writable flags, required media and outputs. Labels are display
text, not alternate input names. Only writable inputs can be submitted.

The standard catalog contains exactly these five templates:

| Family | Template | Task |
| --- | --- | --- |
| `qwen21` | `image_qwen_image_2_1_t2i` | Text to image |
| `qwen21` | `image_qwen_image_2_1_image_edit` | Image editing |
| `ltx23` | `video_ltx2_3_t2v` | Text to video |
| `ltx23` | `video_ltx2_3_i2v` | Image to video |
| `ltx23` | `video_ltx2_3_ia2v` | Image and audio to video |

Use the live catalog for deployment availability and defaults; these are standard
Qwen templates, not separately named distilled variants.

## Submit exact inputs

```bash
hyper flow submit qwen21 image_qwen_image_2_1_t2i \
  --input 'prompt=42' --input seed=0 --input switch=false --json
```

Repeat `--input NAME=VALUE` for scalar inputs. Descriptor `STRING` values remain
strings (`prompt=42` sends `"42"`); other values use JSON types, preserving `0`
and `false`. Dotted names are literal keys, not nested objects.

Upload media with `hyper files upload ./source.png`, then pass the returned
owned file ID using `--media NAME=FILE_ID`. Canonical submission accepts owned
file bindings only, not URLs, local paths or inline media.

```bash
hyper flow submit qwen21 image_qwen_image_2_1_image_edit \
  --input 'prompt=combine these images' \
  --media images.image_1=OWNED_IMAGE_ID \
  --media images.image_5_1=OWNED_FIFTH_IMAGE_ID

hyper flow submit ltx23 video_ltx2_3_ia2v \
  --input 'value=a presenter speaking naturally' \
  --media input=OWNED_IMAGE_ID --media audio=OWNED_AUDIO_ID \
  --input noise_seed=0 --input start_index=0 --input value_4=9
```

For IA2V, `value` is the prompt, `input` the first frame, `audio` the audio input,
`noise_seed` the seed, `start_index` the audio start and `value_4` the duration.
Qwen edit's fifth image is `images.image_5_1`, not `images.image_5`.

## Track the returned record

```bash
hyper flow list --json
hyper flow status RENDER_ID --json
hyper flow wait RENDER_ID --timeout 600 --json
hyper flow cancel RENDER_ID --yes
```

`status` reads the lightweight status endpoint and reports state and progress,
including zero progress. `wait` prints the terminal render record, including its
result URL or error. Failed and cancelled records produce a nonzero exit status.
An accepted pending/running render is not a completed result: retain its ID.

The SDK's existing wait policy adds up to 1,800 seconds of queue grace and
300 seconds of active grace to the requested timeout. `--output`/`-o` selects
the CLI output format, not a download destination; use the returned result URL.
Included history lists up to the latest 100 successful submission records.

An active `render` entitlement (including grants) includes all published flows.
The credential must also delegate flow access: `flows:*` or `*:*` permits the
catalog; restricted keys are not widened. Upload/list/delete needs separate
files permissions, while binding existing owned ready files does not.

Routing uses the server's `/agents/flow/access` render decision, not client-side
subscription or capability guesses. Discovery errors fail without submission.
Submission POSTs are attempted once; an uncertain response must not trigger an
automatic duplicate submission. GET transport retries remain enabled.

## Compatibility helpers

`hyper flow create TYPE` retains typed flags, `--param key=value` and `--dry-run`
for existing callers. Prefer `catalog`, `describe` and `submit` for the exact
current templates and inputs. Python CLI shortcut flags are a separate interface
and are not TypeScript CLI flags.

HiDream and first/last-frame routes and convenience helpers have been removed.
Use one of the five published templates above. Existing render IDs remain
available through the tracking and cancellation interfaces.
