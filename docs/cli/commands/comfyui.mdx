## Managed rendering

For managed Qwen Image 2.1 and LTX 2.3 rendering, use the five-template catalog:

```bash
hyper flow catalog
hyper flow submit ltx23 video_ltx2_3_t2v --input 'value=clouds moving over mountains'
hyper flow get <render_id>
```

See [Flow](/cli/commands/flow) for exact input types and owned-media bindings.

## User-managed ComfyUI

The Python CLI's `hyper comfyui` commands are separate GPU-job tools for your
own workflows. An upstream template appearing in these tools is not a promise
of managed Render support.

```bash
hyper comfyui --help
hyper comfyui list
hyper comfyui show image_qwen_image_2_1_t2i
hyper comfyui run --help
```

Use `show` to inspect the actual workflow before applying parameters. Node IDs,
input names, enabled modes and supported parameters depend on the graph; do not
reuse node IDs from another template. Workflow conversion utilities retain
support for arbitrary user graphs and upstream node types.

The `run` command's existing job lookup, instance reuse, GPU/region selection,
output download and debugging options remain available through `--help`.
These job tools do not change the managed catalog or its server-selected models.
