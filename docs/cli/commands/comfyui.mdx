## Managed rendering

For managed Qwen Image 2.1 and LTX 2.3 rendering, use the five-template catalog:

```bash
hyper flow catalog
hyper flow submit ltx23 video_ltx2_3_t2v --input 'value=clouds moving over mountains'
hyper flow status <render_id>
```

See [Flow](/cli/commands/flow) for exact input types and owned-media bindings.

## User-managed ComfyUI

The former `hyper comfyui` command was removed with the Python CLI.
Use the [Python ComfyUI SDK](/sdk/comfyui) for your own GPU workflows.
Workflow conversion utilities support arbitrary user graphs and upstream node
types; that does not make those graphs part of the managed Render catalog.
