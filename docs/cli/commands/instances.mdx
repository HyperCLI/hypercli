---
title: GPU inventory and jobs
description: Discover GPU capacity and launch jobs with supported interfaces.
---

Use [hyper jobs](/cli/commands/jobs) from `@hypercli.com/cli`:

```bash
npm install -g @hypercli.com/cli
hyper jobs gpus
hyper jobs create --image nvidia/cuda:12.6.3-runtime-ubuntu22.04 --gpu l40s -- nvidia-smi
```

Node.js 22+ is required. The former `hyper instances` and `hyper launch`
commands have been removed with the Python CLI.

For detailed GPU types, regions, prices, and capacity, use the
[Python instances SDK](/sdk/instances). For load balancers and other advanced
launch options, use the [jobs SDK](/sdk/jobs).
