---
title: hyper jobs
description: Inspect jobs, stream logs, watch metrics, exec commands, and open shells.
---

This page describes the current TypeScript CLI unless a section is marked
Python-only.

## Create

```bash
hyper jobs gpus
hyper jobs create --image nvidia/cuda:12.6.3-runtime-ubuntu22.04 --gpu l40s -- nvidia-smi
```

Use `--dry-run` to validate a create request without launching a job.

## list

```bash
hyper jobs list
hyper jobs list --state running
hyper jobs list --output json
```

Repeated `--tag KEY=VALUE` filters are a legacy Python CLI option.

## get

```bash
hyper jobs get <job_id>
hyper jobs get <job_id> --output json
```

Job IDs can be full UUIDs or recent prefixes when the prefix is unambiguous.

## logs

```bash
hyper jobs logs <job_id>
hyper jobs logs <job_id> --tail 200
hyper jobs logs <job_id> --follow
```

The `--tui` and `--cancel-on-exit` log options are Python-only.

## metrics (Python only)

```bash
hyper jobs metrics <job_id>
hyper jobs metrics <job_id> --watch
hyper jobs metrics <job_id> --output json
```

## exec

```bash
hyper jobs exec <job_id> nvidia-smi
hyper jobs exec <job_id> -- python -c 'import torch; print(torch.cuda.device_count())'
```

Important flag:

- `--timeout`

## shell (Python only)

```bash
hyper jobs shell <job_id>
hyper jobs shell <job_id> --shell /bin/sh
```

This opens an interactive PTY over WebSocket.

## extend

```bash
hyper jobs extend <job_id> --seconds 7200
```

## cancel

```bash
hyper jobs cancel <job_id>
```

## Creating Jobs

The legacy Python CLI creates jobs under:

```bash
hyper instances launch ...
```
