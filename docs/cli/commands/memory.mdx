This page covers two different surfaces that share the `hyper memory` name:

- **Session memory (this CLI)**: `search`, `summary`, `chunks`, `tail`, and
  `rebuild` query the hosted session-memory API for an agent's ACP sessions.
- **Local import (Python CLI `hypercli-cli` only)**: `hyper memory import`
  converts local captions/documents into OpenClaw-indexable Markdown. The
  TypeScript CLI has no `import` command.

## Session memory

```bash
hyper memory search <query...> [-s|--session-id ID] [--limit N] [--json]
hyper memory summary <ID> [--json]
hyper memory chunks <ID> [--cursor CURSOR] [--limit N] [--json]
hyper memory tail <ID> [--n N] [--json]
hyper memory rebuild <ID> [--json]
```

`search` accepts free-text terms, optionally scoped to one session with
`--session-id`; `--limit` must be 1-100. `summary` prints a session's summary
(or its pending state). `chunks` pages a session's summarized chunks, printing
the next cursor for further pages. `tail` prints the last `--n` messages
(default 20). `rebuild` triggers the once-per-24h summary rebuild; a rate-limited
call reports its retry-after delay.

## Import (Python CLI `hypercli-cli`)

`hyper memory import` is primarily local file preparation. It accepts one file
or recursively discovers supported files in a directory:

- captions: `.srt`, `.vtt`, `.ttml`
- documents: `.pdf`, `.doc`, `.docx`, `.epub`, `.txt`, `.md`

Install document parsers with `pip install "hypercli-cli[documents]"` before
importing PDF, DOCX, or EPUB sources. Plain text/Markdown and caption support do
not require that extra.

`--collection` is required and selects a path below the memory root:

```bash
hyper memory import ./notes \
  --collection research/project \
  --workspace ~/.openclaw/workspace
```

The default memory root is `<workspace>/memory`. Override it with
`--memory-dir` or `HYPER_MEMORY_DIR`.

For a single input, metadata flags include `--source-id`, `--title`,
`--source-url`, and caption/document-specific fields. These single-file flags
are rejected when importing multiple discovered files. `--raw-json3` applies
only to caption imports, and `--no-copy-raw` omits raw source copies.

## Optional Remote Work

`--enrich` sends sampled content to the HyperCLI `/v1` model API to generate
summary and keyword metadata. It accepts `--model`, `--base-url`, and `--key`.
Without `--enrich`, conversion does not require a HyperCLI API call.

`--index` runs `openclaw memory index` after all imports. Add `--agent <id>` to
pass that agent selection to OpenClaw. Indexing invokes a local subprocess and
fails the command if OpenClaw indexing fails.
