---
title: hyper memory
description: Search hosted ACP session memory and read summaries and history.
---

`search`, `summary`, `chunks`, `tail`, and `rebuild` use the hosted session-memory
API. Local document/caption import was removed with the Python CLI; there is
no `hyper memory import` command in the supported CLI.

```bash
hyper memory search <query...> [-s|--session-id ID] [-a|--agent-id ID] [--cursor CURSOR] [--limit N] [--json]
hyper memory summary <ID> [--json]
hyper memory chunks <ID> [--cursor CURSOR] [--limit N] [--json]
hyper memory tail <ID> [--n N] [--json]
hyper memory rebuild <ID> [--json]
```

`search` accepts free-text terms, optionally scoped to one session with
`--session-id` or one agent with `--agent-id` (both may combine); `--limit`
must be 1-100 and `--cursor` continues an earlier page from its next cursor.
`summary` prints a session's summary or its pending state. `chunks` pages
summarized chunks. `tail` prints the last `--n` messages (default 20).
`rebuild` triggers the once-per-24h summary rebuild; a rate-limited call
reports its retry-after delay.

For durable document uploads and Markdown projections, use the
[Workspace SDK](/sdk/workspaces).
