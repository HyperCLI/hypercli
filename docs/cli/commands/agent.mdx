---
title: hyper agent
description: Read or update canonical Agent soul and role metadata.
---

The TypeScript CLI exposes canonical Agent semantic metadata through the
Backend. These commands do not read or write runtime persona files.

## Soul

```bash
hyper agent <id> soul
hyper agent <id> soul --json
hyper agent <id> soul -f SOUL.md
cat SOUL.md | hyper agent <id> soul -f -
```

Reads emit only Markdown on stdout. `-f` replaces `Agent.meta.soul` with the
file's UTF-8 contents, including empty content. JSON output is
`{"agent_id":"...","soul":"..."}`.

## Role

```bash
hyper agent <id> role
hyper agent <id> role researcher
hyper agent <id> role "  Research / Café  "
hyper agent <id> role ""
```

A role is a short identifier, not a role-file document. Valid values are
nonblank, at most 64 characters, and preserved verbatim. An empty-string set
clears `Agent.meta.role`. An unset role emits zero raw bytes; JSON is
`{"agent_id":"...","role":null}`.

An Agent runtime key may read and update only its own soul and role. Other
credentials must be authorized for the explicit Agent.
