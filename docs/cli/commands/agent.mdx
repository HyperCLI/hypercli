title: hyper agent

`hyper agent` is the account and local-tooling surface for HyperCLI.

Use it for:

- onboarding
- wallet-based subscribe/login
- plan and model discovery
- provider config snippets
- local transcription
- voice and embedding helpers

## Command Inventory

| Area | Commands |
| --- | --- |
| Onboarding and payment | `onboard`, `subscribe`, `login`, `activate-code` |
| Account inspection | `status`, `plans`, `current-plan`, `subscriptions`, `subscription-summary`, `models` |
| Lifecycle aliases | `start`, `stop`, `exec`, `shell` |
| Integrations and config | `enable`, `openclaw-setup`, `config` |
| Inference helpers | `voice`, `embed` |

The `voice` and `embed` entries are nested command groups. Use
`hyper agent voice --help` or `hyper agent embed --help` for their subcommands.

## Commands

### `onboard`

Guided flow for:

- wallet creation
- funding
- plan selection
- subscription
- config generation
- verification

### `subscribe`

Subscribe to a HyperCLI plan through the x402 wallet flow.

```bash
hyper agent subscribe basic
hyper agent subscribe pro 100 --dev
```

### `status`

Show status from the legacy `~/.hypercli/agent-key.json` file. This command
prints a long key prefix; do not paste its output into chat or logs. Prefer
`hyper me` for an authenticated identity/capability check.

### `plans`

List plan IDs, price, and limits.

```bash
hyper agent plans
hyper agent plans --dev
```

### `current-plan`, `subscriptions`, and `subscription-summary`

Inspect the current effective plan, every entitlement/subscription item, or the
pooled effective limits and slot inventory:

```bash
hyper agent current-plan
hyper agent subscriptions
hyper agent subscription-summary
```

Each supports `--json` and `--dev`. JSON can contain account, provider, and
entitlement identifiers; treat it as private account data.

### `activate-code`

Redeem a grant code for the current account:

```bash
hyper agent activate-code <code>
hyper agent activate-code <code> --extend-existing
```

By default redemption creates a new entitlement. `--extend-existing`
explicitly extends the matching entitlement. Treat activation codes as secrets
until redeemed.

### `models`

List HyperCLI inference models.

```bash
hyper agent models
hyper agent models --json
```

### `login`

Wallet-based login that creates a user-bound HyperCLI API key and stores it locally.

### `enable`

Attach the hosted Slack relay to an agent:

```bash
hyper agent enable <agent>
hyper agent enable <agent> --restart --wait
```

Without `--restart`, OpenClaw may need a later restart to read the persisted
Slack configuration. This command changes remote integration state.

### `config`

Generate config snippets for:

- `openclaw`
- `opencode`
- `env`

```bash
hyper config openclaw --apply
hyper config opencode --placeholder-env HYPER_AGENTS_API_KEY
hyper agent config env
```

Without `--apply`, the command prints the generated JSON blob to stdout.

OpenCode configs use `{env:NAME}` for environment variable interpolation:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "hypercli/glm-5-anthropic",
  "provider": {
    "hypercli": {
      "npm": "@ai-sdk/anthropic",
      "name": "HyperCLI",
      "options": {
        "baseURL": "https://api.hypercli.com/v1",
        "apiKey": "{env:HYPER_AGENTS_API_KEY}"
      },
      "models": {
        "glm-5-anthropic": {
          "name": "glm-5-anthropic",
          "limit": { "context": 262144, "output": 65536 }
        },
        "kimi-k2.6-anthropic": {
          "name": "kimi-k2.6-anthropic",
          "limit": { "context": 262144, "output": 65536 }
        }
      }
    }
  }
}
```

The full generated `~/.openclaw/openclaw.json` example lives in:

- [Configuration](/cli/configuration)

With `--apply`, the command:

- writes `~/.openclaw/openclaw.json`
- runs `openclaw models list` to regenerate the active agent `models.json`

It does not restart OpenClaw automatically. Restart when you are ready:

```bash
openclaw gateway restart
```

### `openclaw-setup`

Patch `~/.openclaw/openclaw.json` directly using the saved HyperCLI key.

```bash
hyper agent openclaw-setup
hyper agent openclaw-setup --default
```

With `--default`, the generated OpenClaw config sets the primary coding model to
`hypercli/kimi-k2.6-anthropic`.

### `exec` and `shell`

Compatibility forwards into `hyper agents`.

### `start` and `stop`

Lifecycle aliases accept an agent ID or unique name:

```bash
hyper agent start <agent>
hyper agent stop <agent>
hyper agent stop <agent> --wait --timeout 900
```

An unwaited stop reports **Agent stopping** while runtime cleanup is in
progress. Use `--wait` when the next action depends on the final `STOPPED`
state and released deployment slot.

### `transcribe`

Local faster-whisper transcription, no remote API required.

### `voice`

Voice generation helpers.

### `embed`

Embedding helpers against HyperCLI.

```bash
hyper agent embed text "Document chunk"
hyper agent embed text "Document chunk" --output ./embedding.json
hyper agent embed test
```

`text --json` writes or prints the complete OpenAI-compatible response;
otherwise `--output` writes only the embedding vector. `test` embeds two fixed
sentences and reports dimensions, tokens, and cosine similarity.

## Files Written By `hyper agent`

- `~/.hypercli/agent-key.json`
- optionally `~/.openclaw/openclaw.json` when using `openclaw-setup`

## Recommended Flow

1. `hyper agent plans`
2. `hyper agent subscribe basic`
3. `hyper agent status`
4. `hyper config openclaw --apply`
5. `hyper agents create ...`
