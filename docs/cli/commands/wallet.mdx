---
title: Wallet payments
description: Supported payment interfaces after retirement of the Python CLI.
---

The retired `hyper wallet` command is not part of `@hypercli.com/cli`.
Use the [plans dashboard](https://agents.hypercli.com/plans) for account purchases,
the [x402 wallet guide](/agents/x402-wallet) for headless payment tooling,
or the [Python x402 SDK](/sdk/x402) for programmatic pay-per-use jobs and flows.

Install the supported CLI with `npm install -g @hypercli.com/cli` (Node.js 22+).
Its [flow commands](/cli/commands/flow) use configured platform credentials;
they do not implement wallet checkout.
