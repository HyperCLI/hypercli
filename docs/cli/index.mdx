## Implementations

| | TypeScript CLI (current) | Python CLI (EOL) |
| --- | --- | --- |
| Package | `@hypercli.com/cli` | `hypercli-cli` |
| Install | `npm install -g @hypercli.com/cli` | `pip install hypercli-cli` |
| Runtime | Node.js >= 22 | Python 3 |
| Status | Actively developed | End-of-life since 2026-09-09; retained for reference |

Both ship the `hyper` binary and read the same ~/.hypercli credentials. The
Python CLI carries some surfaces the TypeScript CLI has not ported yet; those
pages are marked below.

## Current Agent Route Model

The CLI now follows the same route defaults as the SDKs:

- `desktop-<host>` = desktop when launched with the desktop flavor
- there is no default `shell-<host>` route

So:

- `hyper agents shell` uses backend `/ws/shell/{agent_id}`
- `hyper agents logs` uses backend `/ws/logs/{agent_id}`
- desktop/browser launches use the OpenClaw pro image and set `HYPER_DESKTOP_ENABLED=1`
