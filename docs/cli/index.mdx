## Install

```bash
npm install -g @hypercli.com/cli
```

Requires Node.js 22+. This package provides `hyper` and reads `~/.hypercli`
credentials. For Python API integrations, use [hypercli-sdk](/sdk/index).

## Command Groups

| Command | Purpose | Reference |
| --- | --- | --- |
| `hyper configure` | Save credentials and API base | [Configuration](/cli/configuration) |
| `hyper me` | Inspect identity and entitlements | [Configuration](/cli/configuration) |
| `hyper agents` | Managed agents, sessions, and access | [agents](/cli/commands/agents) |
| `hyper websearch` | Platform search proxy | [agents](/cli/commands/agents#other-commands) |
| `hyper acp attach` | Publish a local file through Hyper-ACP | [ACP](/cli/commands/acp) |
| `hyper jobs` | GPU inventory and jobs | [jobs](/cli/commands/jobs) |
| `hyper flow` | Managed media flows | [flow](/cli/commands/flow) |
| `hyper files` | Upload, inspect, and delete files | [files](/cli/commands/files) |
| `hyper integrations` | Provider connections and MCP calls | [integrations](/cli/commands/integrations) |
| `hyper memory` | Session memory and summaries | [memory](/cli/commands/memory) |
| `hyper routines` | Scheduled agent prompts | [routines](/cli/commands/routines) |
| `hyper skills` | Skill catalog and export | [skills](/cli/skills) |
| `hyper persona` | Live persona discovery and resolution | [persona](/cli/commands/persona) |
| `hyper voice` | Voice cloning and transcription | [voice](/cli/commands/voice) |
| `hyper agent` | Canonical Agent soul and role | [agent](/cli/commands/agent) |
| `hyper soul` | Read or update canonical SOUL | [soul](/cli/commands/soul) |
| `hyper role` | Read or set role identifier | [role](/cli/commands/role) |
| `hyper user` | Canonical account profile | [user](/cli/commands/user) |

Run `hyper --help` or `hyper <group> --help` for the installed command surface.
The retired Python CLI's account, wallet, workspace, local-memory import,
and inference commands are not part of this CLI. Their former reference pages
link to supported SDK or API alternatives.

## Agent Routes

- `desktop-<host>` is the desktop route when enabled.
- There is no default `shell-<host>` route.
- `hyper agents shell` uses backend `/ws/shell/{agent_id}`.
- `hyper agents logs` uses backend `/ws/logs/{agent_id}`.
- Desktop/browser launches use the standard OpenClaw image and
  `HYPER_DESKTOP_ENABLED=1`.

Start with the [CLI quickstart](/cli/quickstart) and [configuration](/cli/configuration).
