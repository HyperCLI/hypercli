---
title: Hermes Agent SDK
description: TypeScript SDK helpers for creating, starting, and calling Hermes Agent deployments.
---

Use `client.deployments.createAgent("hermes-agent", ...)` for the managed
Hermes runtime. The helper selects image
`ghcr.io/hypercli/hypercli-hermes:latest`, sync root `/home/hermes`,
`syncExclude: ["shared/**"]`, and UID/GID `10000`.

## Create

```ts
import { HyperCLI } from "@hypercli.com/sdk";

const client = new HyperCLI({ agentApiKey: "hyper_api_..." });

let agent = await client.deployments.createAgent("hermes-agent", {
  name: "hermes",
  size: "small",
});
agent = await agent.waitRunning();
```

The SDK seeds no authentication material: your `env` and `secrets` pass
through to the launch contract untouched.

## Start

Start reuses the Backend-stored launch configuration:

```ts
agent = await client.deployments.start(agent.id);
agent = await agent.waitRunning();
```
