## Main Client

```ts
import { HyperCLI } from "@hypercli.com/sdk";

const client = new HyperCLI({
  apiKey: "hyper_...",
  apiUrl: "https://api.hypercli.com",
  timeout: 30_000,
});
```

Use canonical `apiKey` and `apiUrl` for explicit configuration. Otherwise the
SDK reads `HYPER_API_KEY`, product/inference `HYPER_API_BASE`, and independent
direct Agent-control `HYPER_AGENTS_API_BASE` from environment/config and uses
environment `HYPER_AGENTS_API_KEY` only as the final credential fallback.

## `voice`

Major methods:

- `tts({ text, voice?, language?, responseFormat? })`
- `clone({ text, refAudio, language?, xVectorOnly?, responseFormat? })`
- `design({ text, description, language?, responseFormat? })`
- `connect({ timeoutMs? })`
- `ttsStream({ text, voice?, language?, responseFormat?, timeoutMs? })`
- `cloneStream({ text, refAudio, language?, xVectorOnly?, responseFormat?, timeoutMs? })`
- `designStream({ text, description, language?, responseFormat?, timeoutMs? })`

Defaults are `voice: "serena"`, `language: "auto"`, and
`responseFormat: "mp3"`. REST voice methods use SDK-relative `/voice/*` paths
on the agents HTTP client, which resolve to `/agents/voice/*` at the product
API host. Streaming methods connect to `/ws/voice` on the derived agents
WebSocket base. Streaming audio is delivered as ordered `audio` JSON headers,
each followed immediately by one binary payload frame.

## `agent`

Major methods:

- `plans()`
- `currentPlan()`
- `subscriptions()`
- `subscriptionSummary()`
- `entitlements()`
- `purchaseEntitlementFromBalance(planId, { duration, tags?, extendExisting? })`
- `redeemGrantCode(code, { extendExisting? })`
- `updateSubscription(subscriptionId, { planId, quantity })`
- `cancelSubscription(subscriptionId)`
- `createStripeTrialCheckout({ successUrl?, cancelUrl? })`
- `models()`
- `discoveryHealth()`
- `discoveryConfig()`

Important account types:

- `HyperAgentSubscription`
  recurring billing object with `cancelAtPeriodEnd`, `currentPeriodEnd`,
  `planAgentTier`, `slotGrants`, and authoritative `trial` timing when present
- `HyperAgentEntitlements`
  effective account state with `slotInventory`, `pooledTpd`, `activeEntitlementCount`, and `billingResetAt`
- `HyperAgentEntitlement`
  concrete 1:1 entitlement instance, included in
  `subscriptionSummary().entitlementItems`, with expiry, tags, features, and
  related agent bindings
- `HyperAgentSubscriptionSummary`
  combined view with `entitlements`, `subscriptions`, `activeSubscriptions`, and `billingResetAt`
- `HyperAgentSubscriptionMutationResult`
  message wrapper returned by recurring subscription updates
- `HyperAgentGrant`
  unapplied or applied grant record with `type`, `planId`, `duration`, `code`, `tags`, and `appliedAt`
- `HyperAgentGrantRedemptionResponse`
  wrapper returned by balance purchases and grant-code redemption with both the `grant` and resulting `entitlement`

### `CodingAgent`

Hydrated for every `hyper-acp`-fronted runtime. Adds:

- `auth`
  runtime-specific `RuntimeAuthClient`: `methods()`, `status()`, `login()`,
  `logout()`
- `acpConnect(options)`
  ACP client over the backend session proxy (`/ws/acp`)
- `acpPool`
  lazily created `CodingAgentAcpPool` — shared, lease-based ACP connection
- `acpTurnDriver(options)`
  per-session `AcpTurnDriver` bound to a pooled lease
