## Install

```bash
npm install @hypercli.com/sdk
```

Requirements:

- Node.js 18+
- ESM-compatible runtime

## What The TS SDK Covers

The SDK combines:

- HyperCLI platform REST APIs
- HyperCLI deployment lifecycle APIs
- backend WebSocket helpers for logs and shells

```ts
import { HyperCLI } from "@hypercli.com/sdk";

const client = new HyperCLI({
  apiKey: process.env.HYPER_API_KEY,
});
```

## Namespaces

## Current Route Model

The SDK assumes the current OpenClaw route defaults:

- `desktop-<host>` = desktop (pro flavor only)
- custom routes come from the `routes` dict

That means:

- `agent.publicUrl` is the root host
- `agent.desktopUrl` / `agent.vncUrl` point to `desktop-<host>`
- `agent.shellUrl` is only populated when you explicitly define a `shell` route

## Recommended Access Patterns

### Use `client.user.authMe()` for capability introspection

```ts
const auth = await client.user.authMe();
console.log(auth.authType);
console.log(auth.capabilities);
console.log(auth.keyId);
```

This resolves against the main product auth route at `/api/auth/me`.

On Orchestra-backed product surfaces, scoped keys generally need `user:self`
for this call. A flow-only key can still use `client.renders.*` helpers,
because the SDK falls back to `/api/flow/*` when auth introspection is denied.

### Use `client.voice` for subscription voice routes

```ts
const audio = await client.voice.clone({
  text: "Hello from HyperCLI",
  refAudio, // Uint8Array containing reference audio
  responseFormat: "mp3",
});
```

Cloning is the supported speech-generation path for new integrations. Preset TTS
and design helpers remain available for legacy compatibility.

The TypeScript SDK sends these requests through the derived agents API base.
For `apiUrl: "https://api.hypercli.com"`, `client.voice.clone(...)` posts to
`https://api.hypercli.com/agents/voice/clone`.

Streaming voice uses the agents WebSocket base plus `/voice`:

```ts
const session = client.voice.connect();
await session.open();

try {
  for await (const chunk of session.speakClone({ text: "Hello from HyperCLI", refAudio })) {
    handleAudio(chunk.audio);
  }
} finally {
  session.close();
}

for await (const chunk of client.voice.cloneStream({ text: "Hello from HyperCLI", refAudio })) {
  handleAudio(chunk.audio);
}
```

**WebSocket compatibility change:** generation now defaults to raw PCM, not MP3,
in both convenience calls and `VoiceSession`. Chunked PCM automatically requests
`stream_mode: "incremental_pcm"`; no extra caller flag is needed. Only an echoed
START acknowledgement enables unknown `chunk.total` (`null`), with the exact count
validated at DONE. Older servers without the acknowledgement retain known totals
and final markers. Use the returned audio metadata to play PCM; it is not an MP3 file.
For encoded output, pass `responseFormat: "mp3"` to `cloneStream`, or
`format: "mp3"` to `speakClone`. REST defaults and CLI MP3 file/stdout output are
unchanged. `chunks: false` requests assembled audio without automatic incremental
negotiation. `ttsStream` and `designStream` are deprecated but remain callable.

The streaming request frame is a JSON message with `type: "speak"`, an
`op` of `tts`, `clone`, or `design`, a `request_id`, `format`, and `chunks`.
The server replies with `start`, then ordered `audio` JSON headers followed
immediately by binary payload frames, then `done`; server errors throw
`VoiceStreamError`. A session handles one request at a time, and breaking the
iterator early sends `{ type: "cancel" }` for the request.

Preferred current helpers:

- `deployments.logsConnect()`
- `deployments.shellConnect()`

Use the backend WebSocket helpers for shells/logs.

## Quick Start

```ts
import { HyperCLI } from "@hypercli.com/sdk";

const client = new HyperCLI({
  apiKey: "hyper_...",
  agentApiKey: "hyper_api_...",
});

const agent = await client.deployments.createAgent("openclaw_acp", {
  name: "docs-demo",
});

await client.deployments.waitForState(agent.id, ['STOPPED'], 330_000);
await client.deployments.start(agent.id);
const running = await client.deployments.waitRunning(agent.id);
console.log(running.publicUrl);
console.log(running.desktopUrl);
```
