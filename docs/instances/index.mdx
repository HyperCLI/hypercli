Use [hyper jobs](/cli/commands/jobs) from the TypeScript CLI, or the
[Python SDK](/sdk/jobs) for advanced launch options.

## Overview

HyperCLI provides on-demand and spot GPU instances across multiple regions worldwide.

## Quick Start

```bash
# Create a job with L40S GPU
hyper jobs create --image nvidia/cuda:12.6.3-runtime-ubuntu22.04 --gpu l40s -- python train.py

# Create with H100 GPU
hyper jobs create --image nvidia/cuda:12.6.3-runtime-ubuntu22.04 --gpu h100 --count 8 -- torchrun --nproc_per_node=8 train.py
```

## Pricing Model

- **Spot instances** (default): Lower cost, may be preempted
- **On-demand instances**: Higher cost, guaranteed availability

Use the [jobs SDK](/sdk/jobs) `interruptible` option to select spot (`True`)
or on-demand (`False`). Query current pricing with the
[instances SDK](/sdk/instances).

## API Endpoints

- `GET /instances/pricing` - Current GPU pricing
- `GET /instances/types` - Available GPU types
- `GET /instances/regions` - Available regions
