---
title: Quickstart
description: Get started with HyperCLI jobs, flows, plans, and OpenClaw agents.
---

## 1. Install

```bash
npm install -g @hypercli.com/cli
```

Requires Node.js 22+. The legacy Python CLI (`pip install hypercli-cli`) is
end-of-life; the command reference pages flag which implementation covers each
command group.

## 2. Configure

```bash
hyper configure
```

## 3. Verify Account Access

```bash
hyper me
```

## 4. Launch A GPU Job

```bash
hyper jobs create --image nvidia/cuda:12.6.3-runtime-ubuntu22.04 --gpu l40s -- nvidia-smi
```

## 5. Run A Flow

```bash
hyper flow create text-to-image --prompt "a cinematic landscape"
```

## 6. Agent Plans And Inference

```bash
hyper me
```

`hyper me` shows your active plan entitlements and pooled inference. Point an
OpenAI-compatible client at `https://api.agents.hypercli.com/v1` with your API
key, or use the Anthropic Messages route at `https://api.agents.hypercli.com`.
See [Inference](/inference/index) for the current model lineup.

## 7. OpenClaw Agents

```bash
hyper agents create my-agent --runtime openclaw
hyper agents start my-agent
hyper agents shell my-agent
```

See [Agents](/agents/index) for runtimes, sizes, and desktop access.
