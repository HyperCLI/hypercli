---
title: Hermes Agent
description: Run Hermes Agent as a managed HyperCLI runtime.
---

Hermes Agent is a supported managed Agent runtime. Its control surface is ACP:
the managed image runs ACP-natively and is driven through the same agent
session flows as the other managed runtimes.

## Runtime Contract

| Field | Value |
| --- | --- |
| Runtime | `hermes_acp` |
| Image family | `ghcr.io/hypercli/hypercli-hermes` (see [tags](/agents/images)) |
| Persistent root | `/home/hermes` |
| Persistent owner | UID/GID `10000` |

Hermes stores runtime state under `/home/hermes`. The SDK defaults to
full-root-minus-Workspace persistence for that path with `sync_exclude:
["shared/**"]`, and sets `sync_uid=10000`, `sync_gid=10000`. The retained PVC
still carries `/home/hermes/shared`; the exclude only keeps boot-materialized
Workspace projections out of Reef/S3 backup.

## Launch and authentication

The SDK launch helpers seed no authentication material: your `env` and
`secrets` pass through to the launch contract untouched, and no keys are
minted, moved, or retained by the SDK. The model credential is injected by the
backend into the managed runtime.

## Python Create

```python
from hypercli import HyperCLI

client = HyperCLI(agent_api_key="hyper_api_...")

agent = client.deployments.create_agent(
    "hermes_acp",
    name="hermes",
    size="small",
)

client.deployments.wait_for_state(agent.id, {"STOPPED"}, timeout=330)
agent = client.deployments.start(agent.id)
agent = agent.wait_running()
```

## TypeScript Create

```ts
import { HyperCLI } from "@hypercli.com/sdk";

const client = new HyperCLI({ agentApiKey: "hyper_api_..." });

let agent = await client.deployments.createAgent("hermes_acp", {
  name: "hermes",
  size: "small",
});

await client.deployments.waitForState(agent.id, ["STOPPED"], 330_000);
agent = await client.deployments.start(agent.id);
agent = await agent.waitRunning();
```

For SDK-specific start examples and client method names, see
[Python Hermes SDK](/sdk/hermes) and [TypeScript Hermes SDK](/ts-sdk/hermes).
