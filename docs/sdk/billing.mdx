title: Billing
description: Check balances and inspect transaction history from the Python SDK.

`client.billing` covers wallet balances and ledger-style transaction history.

HyperCLI plan billing is exposed separately through the Agents API. The current
Python SDK surfaces are split between `client.agent` and `client.deployments`:

- `client.agent.subscriptions()`
  recurring billing objects, including `cancel_at_period_end`
- `client.agent.subscription_summary()`
  combined account view with active subscriptions plus effective and concrete
  entitlements (`summary.entitlement_items`)
- `client.agent.entitlements()`
  the same account summary shape, including slot inventory, pooled inference,
  concrete entitlement items, and `billing_reset_at`
- `client.agent.cancel_subscription(subscription_id)`
  schedule a recurring Stripe subscription for cancellation at period end
- `client.agent.update_subscription(subscription_id, plan_id=..., quantity=1)`
  change a recurring subscription using one canonical plan and quantity
- `client.deployments.redeem_grant_code(code, extend_existing=...)`
  apply an activation-code grant
- `client.deployments.purchase_entitlement_from_balance(...)`
  charge Orchestra balance and apply the resulting grant

Concrete entitlement items are included in
`subscription_summary().entitlement_items`. Subscription updates use one
canonical `plan_id` and a positive `quantity`; use the dedicated cancellation
method to cancel at period end.

## Balance

```python
from hypercli import HyperCLI

client = HyperCLI()
balance = client.billing.balance()

print(f"Total: ${balance.total}")
print(f"Available: ${balance.available}")
print(f"Rewards: ${balance.rewards}")
print(f"Paid: ${balance.paid}")
```

### Balance Fields

| Field | Type | Description |
| --- | --- | --- |
| `total` | `str` | Total balance in USD |
| `available` | `str` | Spendable balance after reservations |
| `rewards` | `str` | Rewards balance |
| `paid` | `str` | Paid balance |

## Transactions

```python
transactions = client.billing.transactions(limit=50, page=1)

for tx in transactions:
    print(f"{tx.transaction_type}: ${tx.amount_usd} ({tx.status})")
```

Fetch one transaction directly:

```python
tx = client.billing.get_transaction("transaction_id")
```

### Transaction Fields

| Field | Type | Description |
| --- | --- | --- |
| `id` | `str` | Transaction ID |
| `amount` | `int` | Amount in smallest units |
| `amount_usd` | `float` | USD amount |
| `transaction_type` | `str` | `top_up`, `job`, `llm`, `refund`, and related values |
| `status` | `str` | `PENDING`, `COMPLETED`, `FAILED` |
| `rewards` | `bool` | Whether rewards balance was used |
| `job_id` | `str` | Associated job ID when present |
| `created_at` | `str` | Creation timestamp |
