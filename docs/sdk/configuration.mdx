## Resolution Order

Credentials resolve from an explicit canonical `api_key`, environment
`HYPER_API_KEY`, the canonical key in `$HYPER_HOME/config` (default
`~/.hypercli/config`), then environment `HYPER_AGENTS_API_KEY` as the final
fallback. A saved canonical key takes precedence over the runtime fallback.

The product base resolves from an explicit `api_url`, environment
`HYPER_API_BASE`, the canonical config's `HYPER_API_BASE`, then
`https://api.hypercli.com`.

## Environment Variables

| Variable | Description |
| --- | --- |
| `HYPER_API_KEY` | Main HyperCLI API key |
| `HYPER_API_BASE` | REST API base URL. Defaults to `https://api.hypercli.com`; the agents REST and WebSocket bases are derived from it |
| `HYPER_AGENTS_API_KEY` | Platform runtime key; final credential fallback |

## URL Model

The Python SDK treats the main API and the agents API as separate surfaces.
`HYPER_API_BASE` is the only base URL setting; every per-service base is
derived from it:

- `HYPER_API_BASE`
  - primary product/backend API
  - billing
  - jobs
  - keys
  - user/account APIs
- product WebSocket base
  - derived from `HYPER_API_BASE` by scheme swap
- agents REST base
  - derived from `HYPER_API_BASE`
  - agent lifecycle
  - files
  - exec
  - desktop tokens
  - deployment metadata
- agents WebSocket base
  - derived from the agents REST base
  - `/logs/{agent_id}`
  - `/shell/{agent_id}`

Default production value:

```bash
HYPER_API_BASE=https://api.hypercli.com
```

Default dev value:

```bash
HYPER_API_BASE=https://api.dev.hypercli.com
```

Production derives `https://api.hypercli.com/agents` as the agents REST base
and `wss://api.agents.hypercli.com/ws` as the agents WebSocket base; dev
derives the `api.dev.hypercli.com` and `api.agents.dev.hypercli.com`
equivalents. A custom `HYPER_API_BASE` keeps its origin and gains an `/agents`
path suffix for the agents REST base.

`HYPER_AGENTS_API_BASE` and independent workspace, routine, runner, and
integration base settings are unsupported. Public CLI `--dev`/`--prod` flags
are unsupported; select an environment using the canonical base.

## Shared Config File

Path:

```text
~/.hypercli/config
```

Example:

```bash
HYPER_API_KEY=hyper_...
HYPER_API_BASE=https://api.hypercli.com
```

Use the SDK helper to write it:

```python
from hypercli import configure

configure("hyper_...")
configure("hyper_...", "https://api.dev.hypercli.com")
```

## Constructor Overrides

```python
from hypercli import HyperCLI

client = HyperCLI(
    api_key="hyper_...",
    api_url="https://api.hypercli.com",
)
```

## Exported Constants

```python
from hypercli import GHCR_IMAGES, COMFYUI_IMAGE
```

- `GHCR_IMAGES`: base GitHub Container Registry namespace
- `COMFYUI_IMAGE`: default image used by `ComfyUIJob`
