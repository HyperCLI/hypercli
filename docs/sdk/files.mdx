---
title: Files
description: Upload local files, bytes, URLs, and base64 payloads for use in render workflows.
---

Upload any file, including archives, PDFs, and other binary payloads. Multipart uploads retain the original basename. Files are retained for 30 days; `expires_at` is the file's retention deadline, not the lifetime of a signed link.

Use `url` as the internal storage reference for HyperCLI workflows. For downloads, use the ready file's `download_url`, or send an authenticated `GET /api/files/{id}/download` to the product API. It redirects to a signed storage URL that preserves the original filename. Follow the redirect without forwarding the product credential. Treat signed links as credentials; do not log them.

## Upload From Disk

```python
from hypercli import HyperCLI

client = HyperCLI()
file = client.files.upload("./face.png")

print(file.id)
print(file.url)
```

## Upload From Bytes

```python
file = client.files.upload_bytes(
    content=image_bytes,
    filename="generated.png",
    content_type="image/png",
)
```

## Async URL And Base64 Imports

`upload_url()` and `upload_b64()` return immediately and usually start in `processing` state.

```python
file = client.files.upload_url("https://example.com/image.png")
file = client.files.wait_ready(file.id)
```

```python
file = client.files.upload_b64(base64_payload, "image.png", "image/png")
file = client.files.wait_ready(file.id, timeout=30)
```

## Use With Renders

```python
image = client.files.upload("./face.png")
audio = client.files.upload("./speech.wav")

render = client.renders.speaking_video(
    prompt="A person speaking naturally",
    image_url=image.url,
    audio_url=audio.url,
)
```

## Metadata And Deletion

```python
current = client.files.get(file.id)
if render.result_file_id:
    output_file = client.files.get(render.result_file_id)
client.files.delete(file.id)
```

## File Fields

| Field | Type | Description |
| --- | --- | --- |
| `id` | `str` | File UUID |
| `user_id` | `str` | Owner user ID |
| `filename` | `str \| None` | Original basename when available |
| `content_type` | `str \| None` | MIME type when known |
| `file_size` | `int \| None` | Size in bytes when known |
| `url` | `str \| None` | Internal storage reference used by HyperCLI workflows |
| `download_url` | `str \| None` | Download link when available |
| `expires_at` | `str \| None` | File retention deadline |
| `state` | `str \| None` | `processing`, `done`, or `failed` for async uploads |
| `error` | `str \| None` | Backend error for failed async uploads |
| `created_at` | `str \| None` | Upload timestamp |
