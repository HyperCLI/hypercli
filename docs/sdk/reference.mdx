## Main Client

```python
from hypercli import HyperCLI

client = HyperCLI(
    api_key=None,
    api_url=None,
    agent_api_key=None,
    agent_dev=False,
    agents_api_base_url=None,
    agents_ws_url=None,
)
```

## `client.voice`

Major methods:

- `tts(text, voice="serena", language="auto", response_format="mp3", timeout=None)`
- `clone(text, ref_audio=..., language="auto", x_vector_only=True, response_format="mp3")`
- `design(text, description=..., language="auto", response_format="mp3")`
- `connect(timeout=None)`
- `tts_stream(text, voice="serena", language="auto", response_format="mp3", timeout=None)`
- `clone_stream(text, ref_audio=..., language="auto", x_vector_only=True, response_format="mp3", timeout=None)`
- `design_stream(text, description=..., language="auto", response_format="mp3", timeout=None)`

REST voice methods use SDK-relative `/voice/*` paths on the agents HTTP client,
which resolve to `/agents/voice/*` at the product API host. Streaming methods
connect to `/ws/voice` on the derived agents WebSocket base. Streaming audio is
delivered as ordered `audio` JSON headers, each followed immediately by one
binary payload frame.

## `client.deployments`

Billing-backed deployment helpers:

- `purchase_entitlement_from_balance(plan_id, duration=..., tags=None, extend_existing=None)`
- `redeem_grant_code(code, extend_existing=None)`

Important account types:

- `HyperAgentSubscription`
  recurring billing object with `cancel_at_period_end`, `current_period_end`, `plan_agent_tier`, `slot_grants`, and optional `trial` timing
- `HyperAgentSubscriptionTrial`
  current Team trial details with nullable `days`, `starts_at`, `ends_at`, and `seconds_remaining`
- `HyperAgentStripeCheckoutResponse`
  Stripe-hosted checkout destination returned by `create_stripe_trial_checkout()`
- `HyperAgentEntitlements`
  effective account state with `slot_inventory`, `pooled_tpd`, `active_entitlement_count`, and `billing_reset_at`
- `HyperAgentEntitlement`
  concrete 1:1 entitlement instance, including expiry, tags, features, and related agent bindings
- `HyperAgentSubscriptionSummary`
  combined view with `entitlements`, `subscriptions`, `active_subscriptions`, and `billing_reset_at`
- `HyperAgentSubscriptionMutationResult`
  message wrapper returned by recurring subscription updates
- `HyperAgentGrant`
  unapplied or applied grant record with `type`, `plan_id`, `duration`, `code`, `tags`, and `applied_at`
- `HyperAgentGrantRedemptionResponse`
  wrapper returned by balance purchases and grant-code redemption with both the resulting `grant` and `entitlement`
